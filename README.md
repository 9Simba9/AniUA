# AniUA 🎌

A desktop application for tracking and browsing anime, built with **C#** and **WinForms** with a local database.

---

## Features

### 👤 User System
- Registration & login with validation (nickname, email, password)
- Auto-login on next launch
- Profile editing: nickname, email, avatar (max 5MB, 1:1 ratio)
- Personal statistics

### 🎬 Anime Browsing
- Browse anime catalog from the main page
- Search by title or original title
- View anime stats and user comments with ratings
- Add anime to personal lists: **Watching** / **Saved**

### 💬 Comments & Ratings
- Leave a comment with a rating slider
- Option to submit rating-only (without text)

### 🛠️ Admin Panel
- Manage users (edit roles, data)
- Manage comments (edit/delete)
- Add and edit anime entries

---

## Tech Stack

- **Language:** C#
- **UI:** WinForms (Windows desktop)
- **Database:** Local DB (SQL)
- **Pattern:** OOP / Layered architecture

---

## Getting Started

1. Clone the repository
2. Open the solution in **Visual Studio**
3. Build and run the project
4. On first launch — register a new account
5. To access admin panel — set user role to `admin` in the database
